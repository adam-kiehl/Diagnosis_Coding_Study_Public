# The Impact of AI Assistance on the Reliability and Speed of Veterinary Clinical Diagnosis Coding

This repository contains code for data collection and analysis for a study performed at Colorado State University on the impact of [AI assisted diagnosis coding](https://journals.plos.org/digitalhealth/article?id=10.1371/journal.pdig.0001147) on the 1) reliability and 2) speed of clinical diagnosis coding. The study manuscript can be found on (arXiv)[].

## Abstract

Electronic veterinary medical records represent a large data resource for veterinary and One Health clinical research. Their use is limited by interoperability challenges, including inconsistent data formats and data siloing. Although resource-intensive, clinical coding with standardized medical terminologies enhances the quality of medical records and facilitates interoperability across sites and species. This study evaluated whether a previously developed AI model capable of inferring 7,739 standardized diagnosis codes from veterinary free text could improve the reliability and speed of clinical coding among individuals with varying levels of expertise. Relative to manual coding, AI-assisted coding was associated with a model-adjusted 48% increase (0.50 vs. 0.73, p < 0.0001) in inter-coder reliability and a 36% reduction (73.0 seconds vs. 46.6 seconds, p < 0.0001) in coding time across professional veterinary coder, specialty-trained veterinary clinician, and veterinary student groups. In exploratory group-specific analyses, professional coders assigned the greatest mean number of codes per record but showed the smallest reduction in coding time with AI assistance. Veterinary clinicians exhibited relatively low inter-coder agreement, while students assigned fewer codes per record. Because clinical coding is resource-intensive and is not currently standard in veterinary medicine, AI assistance may provide a practical pathway to unlock significant data to support clinical and translational veterinary research at scale.

## Code Summary

This repository contains the following directories:
- `analysis`: Analysis scripts (`IRR_PowerAnalysis.Rmd` and `Coding Study Analysis.Rmd`) including power analysis, EDA, and results analysis.
- `data_entry`: Streamlit data collection app and associated utilities.
- `fine_tuned`: A placeholder for fine-tuned model state object.
- `plots`: Plots generated by `Coding Study Analysis.Rmd` for the manuscript.

Several files were removed from this repository due to privacy and logistics considerations:
- `analysis/gatortron_predictions.json` contained model predictions for every record.
- `data_entry/records_df.csv` contained clinical text and collected study data.
- `data_entry/CONCEPT_RELATIONSHIP.csv` can be downloaded from [ATHENA](https://athena.ohdsi.org/search-terms/start).
- `fine_tuned/model_save_gator.pkl` can be downloaded from [PhysioNet](https://physionet.org/content/vet-diagnosis-coding/1.0.0/).
